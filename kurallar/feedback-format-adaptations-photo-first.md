User, 2026-11-01: "elinden geldiğince görsel üreterek ilerle, referanslarının çoğu o şekilde; yazılı olanlarda çok fazla üretime gitme". The first pass of the Kasım format page was PNGs on flat colour while the references were photo scenes.

**Why:** a reference's strength is usually the staged image; a flat layout keeps the copy but loses the format.

**How to apply:** compare each frame to its reference at full size first. If the reference is a photo scene, generate the scene and set the existing copy on it. Leave text, UI and real proof formats (real B/A, real reviews, founder or podcast shots) alone. For images used with text, leave the copy space in the prompt so nothing needs moving later.

User, 2026-11-02 corrections on the same page:
- A meme reference stays a meme; do not turn it into a staged photo.
- Simple words that belong to the scene (billboard copy) go in the prompt; Nano Banana renders them cleanly. Do not overlay them in Figma.
- Keep the small devices of the reference, such as arrows and notes on a before/after.
- Check people against the copy: "two friends" means the founders, both women.
- UI mockups use auto layout and concentric radii (inner radius = outer radius minus padding).
- Handwritten notes need a font that reads as real handwriting, not a marker display face; test several first.

- Video formats (podcast, countdown, founder-led, UGC) are delivered as videos with Drive links, not as a static frame.
- A reference sets the idea, not the colour: background follows our white scientific look over the reference tone.
- Check the reference's layout for overlays too: reviews scatter around the product, not in columns.

2026-11-02, B03: "olmadı, daha dinamik olmalı referanstaki gibi". Two calm card-holding shots failed before I read the reference closely. A hook reference's energy lives in the pose and lens (arm thrust at camera, huge foreshortened hand, diagonal body, flying hair); match that first. A notification card over the hand is a flat Figma UI layer placed over the face, not a card drawn in the photo.
