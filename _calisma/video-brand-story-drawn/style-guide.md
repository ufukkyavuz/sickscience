# Style guide: drawn brand story

- **Material:** a real paper surface (cream-white, faint paper grain, a little pencil-guide dust), black fine-liner ink lines, hand drawing. The drawing appears line by line (draw-on), as if a hand were drawing, never a vector reveal.
- **Colour:** only the brand colours, as marker fills. ShapeShift violet #7B2FD6, NetWork red #D7263D, PowerCycle green #4CB944, DropOff cobalt #1F3FD1, SickScience magenta #A921C0 (logo). Everything else is black ink on paper.
- **Type:** Founders Grotesk for captions (bold, centred); the drawn words on paper are hand-lettered (the CLAUDE.md exception for a hand-lettered prop).
- **People:** Merve and Polen as simple line portraits based on the existing founder elements (ss-founder-merve / polen). No realistic face; recognisable silhouette, hair, lab coat.
- **Motion:** each scene starts from the previous drawing (the page turns or the pen keeps going). No hard cuts; the camera moves slowly over the paper (small parallax and push).
- **Sound:** a soft pen-scratch effect, a light piano/plucked bed, -14 LUFS. VO lead; few SFX (pen, page turn, one "ding" on the logo).
- **Production:** each scene's drawing is made as a still in Higgsfield Nano Banana Pro (Unlimited) in this style → a "line-by-line drawing" reveal done in code by mask (Hyperframes). The real product shows only in the final frame.
- **Avoid:** clip-art / cartoon look, gradients, 3D, emoji, AI-slop character faces.
