On 2026-10-30 the user asked why INO's staged video method wasn't known here. It lived only in INO memory.

**Why:** project memories don't cross over, so SickScience work missed lessons already paid for in INO.

**How to apply:**
- Script beats: hook (question, pattern break or result first) → lead (holds to 10 s) → body → open loop → body → CTA, with VO + word-synced captions. Source: `INO Claude Ads/MD/REELS-REFERANS-ANALIZ-2026-10-27.md`.
- Production stages: brief → storyboard + variety audit → build → QC → sound → delivery (`ino-motion` skill).
- Music: real Pixabay tracks fitted to the cuts, never mgaudio beds (user on INO: "müzikler tırt"). mgaudio is for SFX only.
- Before a video job here, check the INO memory index for newer video lessons.
