User 2026-10-20 (ShapeShift VO v3 ingredient pop-ins): "gerçek fotoğraf gibi üreteceğine direkt bulabilirsin… ikon olarak da koyabilirsin… boşuna üretmene, meşgul etmene gerek yok".

**Why:** Common objects already exist as icons. Generating them occupies the Higgsfield queue, which other sessions share.

**How to apply:**
- Use Google Noto Emoji (Apache 2.0, commercial use OK): `https://fonts.gstatic.com/s/e/notoemoji/latest/<codepoint>/512.png`. The GitHub raw paths return 404.
- Check the glyph first: 🫘 1fad8 is a kidney bean, not coffee. Caffeine = ☕ 2615, niacinamide = 🧪 1f9ea, pineapple = 🍍 1f34d, gel = 💧 1f4a7.
- Style the icons as stickers: white outline, soft shadow, a purple label pill centred with textbbox, spring pop-in on the spoken word, plus a pop SFX.
- Generate only when the visual is brand-specific (the products themselves).
