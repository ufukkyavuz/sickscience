SickScience 2026-10-01: after I set copy in Figma with a templated stack (mono eyebrow, text wordmark, left-aligned block, pill CTA), the user said the typography Higgsfield itself produced in the first batch was far better and told me to drop the "saçma ai slop" style.

**Why:** Template-looking layouts read as generic AI output; the ad needs one bold, scene-integrated headline treatment.
**How to apply:** For text in Figma, use big uppercase headlines fitted to frame width (Inter Bold centered or Anton condensed), one accent-colour line, one plain supporting line, CTA only for a real offer, nothing decorative.
