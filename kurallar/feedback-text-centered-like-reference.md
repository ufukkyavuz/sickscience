On 2026-10-27, while adapting the Prequel references, I put text in right-aligned or left-aligned columns: callout blocks, set review, "skin secret" stacks. I did this to keep the text off the product. The user reacted twice, angrily:
- "yazıları sağa yaslama… referansların hangisinde öyle"
- "yine yazıların sağda kaldığı görseller var"

In the end the user fixed the rest by hand.

**Why:** every one of the references centres its text. A side column reads as a different, worse layout.

**How to apply:**
- Copy the reference's alignment. For these references that means centred lines and stacks centred on the frame.
- If a centred stack would cover the product, change the photo, not the alignment:
  - pick a frame with empty space above the product, such as the lab-stand shot S_1143 or the Old Image shot SS0880;
  - or change the crop.
- Before delivery, check every frame's text x-position. A side column only goes in when the user asks for it.
