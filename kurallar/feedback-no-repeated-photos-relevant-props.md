Feedback from 2026-10-25 → 2026-10-27, on the Halloween and Prequel-reference series:

1. **No repeated photos.** "hep aynı fotoğrafı kullanma bro ya". The skeleton shot appeared in 3 Halloween creatives and the red-foil shot in 2. Within one series, each creative uses a different client photo, and preferably a different set. Two different frames from the same shoot still read as repetition. Before delivery, list photo → creative and remove duplicates.
2. **Layouts must differ too.** "bu layoutlar hep aynı gidiyo". Logo top, headline top, photo below on every frame was rejected. Use a different structure per concept: split TRICK/TREAT, a Notes-app checklist card, giant type behind a cut-out subject. See [[feedback-vary-layouts]].
3. **Props must make sense for the product.** "bal kabağı ne alaka burda?". PowerCycle (hair) shown on pumpkins was rejected outside a Halloween context. When the reference is UGC/native, use realistic phone-shot photos or scientific/lab photos.
4. **Which folder for which shot:**
   - Hand-held / native: UGC Set, the Ulta bathroom video frames, or Dropbox UGC.
   - Not hand-held: the scientific folders "All Products - New Image" (lab stand S_1133–1143, petri dishes S_0883–0901) and "Old Image" (SS0880 ShapeShift on a glass block with a pineapple beaker, SS0547 trio lined up, SS0628/SS0763 gloved lab tray). The user asked for this explicitly: "elde tutulmayanları … bilimsel tarzda olan 2 klasörden fotoğraf seç".
5. **Selfie frames are mirrored.** Frames from front-camera videos (the Ulta bathroom routine) show the label reversed. Flip horizontally (`ImageOps.mirror`) and zoom in to check that "SickScience" / "NetWork" read correctly before use.
6. **Check the type of claim.** Prequel says "My dermatologist's skin secret"; we have no dermatologist, so we used the true "Two cancer researchers' skin secret". A real review is labelled "customer review", not "verified", unless verification is known.
