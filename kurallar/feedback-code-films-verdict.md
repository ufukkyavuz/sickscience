User verdict on the first opuscar tests (2026-10-21).

**Swiss v1 rejected:** "marka renkleriyle alakası yok" plus a drawn product. v2 fixed both: white, black and logo pink #C027B3 with the real product photos (ERH_7470B closed, ERH_7472B open pump, ERH_7474B cap; cap-lift move).

**Drawn product:** "direkt ürünü kullansaydın". Never redraw the product in code films. Use the client PNGs: Products/png ERH_* and Products/sets/ss-set-*.

**One flat video is not a test:** "1 tane video yapmışsın o da dümdüz". When testing a tool, make several films in clearly different grammars (3D, character, kinetic type…).

**Code-drawn talking character:** rejected even after a redesign ("beğenmedim"). Don't pitch code-drawn characters for ads. Use Higgsfield/Veo for people.

**Overall:** "bunlar işimize yarayacak, bazı noktalarda kullanabilirsin". Use code films as components:
- offer and price animations
- stats builds
- 3D product moments
- end cards
