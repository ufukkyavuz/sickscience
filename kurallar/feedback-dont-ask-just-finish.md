User, 2026-11-05: "şunu da güncellesene aq bana soru sorup durma ya". I had reported "the new image is ready, should I place it?" and waited, instead of putting it into the Figma frames myself.

**Why:** the user expects finished work in Figma, not a status report plus a question.

**How to apply:**
- Once a fix is asked for, carry it through: regenerate, upload into every format (Story, Feed, Square), lay it out, check it, then report.
- Only stop to ask for a real blocker the user alone can resolve.
- If the Figma desktop app is busy because the user is working in another file, don't send keys there. Use the Figma API/MCP (upload, crop, rescale) and finish the placement. List the desktop-only steps (Expand) as remaining work in the final report, not as a question.
