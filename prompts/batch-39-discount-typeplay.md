# Batch 39 — Discount statics where the type plays with the photo (2026-10-11)

User: "az önce yaptığın şekilde textlerle de oynayalım, dümdüz olmasın… şu ankine dokunma, yeni birkaç tane çıkar."
The type has to interact with the photo, not sit on top of it:
- products form a character;
- a loupe magnifies the copy;
- giant type sits behind the products (cutout layer in Figma, made with OpenCV grabCut).

Offers used, all live on the site:
- Vault Value Set: 20% off, $180 → $144.
- Subscribe & Save: 15% off every refill, free shipping.
- GLP-1 Facial Recovery System: $162 → $137.

Production: 9:16 masters made in the Higgsfield web UI with Unlimited. Story, Feed and Square are crops of the same master.
