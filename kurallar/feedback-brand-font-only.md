Every text layer uses Founders Grotesk (Regular/Medium/Semibold/Bold, Condensed, X-Condensed cuts). Never IBM Plex Mono, Inter or any other family for ad copy. Exception: handwriting that is physically part of the scene (sticky notes, paper notes) uses a handwriting font such as Permanent Marker — user confirmed this is fine for that concept.

**Why:** user (2026-10-03) saw mono and marker fonts I had copied from competitor references and said to use the brand font only.

**How to apply:** when a reference uses a different typeface style, imitate it with a Founders cut (e.g. mono caps → Founders Medium caps with tracking; in-scene handwriting stays handwritten). Run a font-family audit on the frames before showing work. Related: [[feedback-type-scale-and-no-blur]].

**Update 2026-10-05:** no Condensed / X-Condensed cuts at all (user: "condensed kullanmayalım, beğenmedim"). Headlines use regular-width Founders Grotesk Semibold/Bold; shrink or break lines instead of condensing. Applies to Figma and video (HyperFrames) typography.
